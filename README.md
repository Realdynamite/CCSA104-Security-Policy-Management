# CCSA104 – Security Policy Management

## Overview

This repository contains my CCSA104 Security Policy Management assignment, completed as part of my Check Point Security Administration coursework.

The assignment focuses on understanding how security policies are created, organised, managed and enforced using Check Point SmartConsole.

## Practical Environment

The practical exercises were carried out using the school-provided remote environment through OpenVPN and Check Point SmartConsole.

The scenario used in the assignment is based on **Orion Logistics**, an organisation with:
- An internal network
- A Demilitarised Zone (DMZ) hosting web and mail servers
- An external network

## Topics Covered

- Exploring the default security policy
- Creating network and host objects
- Building an Access Control rulebase
- Understanding Stealth and Cleanup Rules
- Organising security rules into sections
- Understanding automatic Hide NAT
- Rule ordering and first-match processing
- Publishing and installing security policies
- Global Properties and Policy Packages
- Security Zones

## Assignment Structure

The submission covers:

- **Part A:** Practical Security Policy Management activities.
- **Part B:** Theory questions on Check Point security policy concepts.

Some practical activities could not be fully completed because certain controls in the school-provided environment became unavailable. These limitations and the available practical evidence are documented honestly in the submitted report.
